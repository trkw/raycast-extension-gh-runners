# raycast-extension-gh-runners

[Raycast](https://www.raycast.com/) extension for self-hosted GitHub Actions runners, built on the [`gh runners`](https://github.com/trkw/gh-runners) GitHub CLI extension.

The extension lives in [`extensions/gh-runners`](extensions/gh-runners); see its README for the commands and setup.

```sh
cd extensions/gh-runners
npm install
npm run dev    # load it into Raycast (ray develop)
```
